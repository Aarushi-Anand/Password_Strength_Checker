# Password Strength Checker

This is a terminal-based password strength checker written in Python. The script evaluates the strength of a given password based on its length, complexity, and whether it is commonly used.

## Features

- **Common Password Check**: Checks if the password is among commonly used passwords listed in `common.txt`.
- **Scoring System**: Scores the password based on:
  - Inclusion of digits
  - Inclusion of lowercase letters
  - Inclusion of uppercase letters
  - Inclusion of special characters
- **Feedback**: Provides feedback on the strength of the password (weak, moderate, strong).

## Installation

1. **Clone the repository**:

    ```bash
    git clone https://github.com/Aarushi-Anand/Password_Checker.git
    ```

2. **Navigate to the project directory**:

    ```bash
    cd Password_Checker
    ```

## Files

1. password_checker.py: The main script that checks password strength.
2. common.txt: A list of commonly used passwords.
